# Link2Global 跨境电商自动化上架系统 - 原型文档（V1.1）

# 一、文档说明

## 1.1 文档目的

明确系统各页面布局、交互逻辑、功能入口及操作流程，为前端开发、后端对接、测试验收提供统一标准，确保开发成果与PRD需求一致，实现“1688采集→本地化处理→一键发布”的全流程自动化。

## 1.2 适用对象

前端开发工程师、后端开发工程师、测试工程师、产品经理、运营人员

## 1.3 原型范围

覆盖系统核心模块：登录注册、首页、1688采集（单链接/批量）、商品本地化处理、智能定价、平台发布、商品管理、系统设置，不包含后期迭代的AI选品、视频生成等功能。

## 1.4 交互规范

- 按钮交互：点击有反馈（颜色变深/轻微缩放），禁用状态灰色不可点击

- 表单交互：输入错误有提示（红色文字），必填项标“*”，提交前校验

- 弹窗交互：弹窗出现时背景置灰，支持点击关闭/确认，批量操作有二次确认

- 加载交互：采集、翻译、发布等耗时操作，显示加载动画+进度提示

- 导航交互：左侧导航栏高亮当前所在页面，支持折叠/展开

# 二、全局通用组件

## 2.1 顶部导航栏（所有页面通用）

布局：左侧系统Logo，中间空白，右侧用户信息+退出按钮

- Logo：Link2Global，点击跳转首页

- 用户信息：显示用户名/头像，hover弹出下拉菜单（个人中心、账号设置、退出登录）

- 通知中心：铃铛图标，有未读通知时显示红点，点击查看任务失败/成功通知

- 退出登录：点击弹出确认弹窗，确认后跳转登录页，清除本地缓存

## 2.2 左侧导航栏（所有页面通用）

布局：垂直排列，可折叠/展开，当前页面导航项高亮（背景色加深）

- 首页

- 商品采集（展开子菜单：单链接采集、批量采集）

- 商品管理（展开子菜单：草稿箱、已采集商品、已发布商品）

- 平台管理（展开子菜单：TikTok Shop授权、Shopee授权）

- 系统设置（展开子菜单：定价设置、翻译设置、图片设置、安全设置）

- 帮助中心

## 2.3 通用弹窗

- 确认弹窗：标题+提示文本+确认按钮+取消按钮（如删除商品、退出登录）

- 提示弹窗：标题+提示文本+确认按钮（如操作成功、操作失败、参数错误）

- 表单弹窗：标题+表单内容+确认按钮+取消按钮（如编辑SKU、设置定价参数）

## 2.4 加载组件

- 页面加载：全屏灰色背景+加载动画（旋转圆圈）+ 提示文本（如“正在加载，请稍候...”）

- 局部加载：按钮/表格区域显示小型加载动画，不遮挡整个页面

- 进度提示：耗时操作（如批量采集、批量发布）显示进度条+百分比（如“采集进度：35%”）

# 三、核心页面原型详情

## 3.1 登录页

### 3.1.1 页面布局

居中卡片式布局，背景为浅灰色，卡片内包含登录表单，底部有注册入口、忘记密码入口

### 3.1.2 核心元素

- 系统Logo：居中显示在卡片顶部

- 登录表单（必填项标“*”）：
        

    - 用户名/手机号输入框：placeholder“请输入用户名或手机号”

    - 密码输入框：placeholder“请输入密码”，支持显示/隐藏密码（眼睛图标）

    - 记住密码：勾选框+“记住密码（7天）”文本

    - 登录按钮：宽度100%，默认可点击，点击后显示加载动画，校验失败显示错误提示

- 辅助入口：

    - 忘记密码：点击跳转“忘记密码”页面（输入手机号→接收验证码→重置密码）

    - 没有账号？立即注册：点击跳转注册页

### 3.1.3 交互逻辑

- 输入校验：用户名/密码为空时，点击登录提示“请输入用户名/密码”

- 登录失败：提示“用户名或密码错误，请重新输入”

- 登录成功：自动跳转首页，记住密码则下次登录自动填充用户名/密码

## 3.2 注册页

### 3.2.1 页面布局

与登录页一致，居中卡片式布局，表单替换为注册表单

### 3.2.2 核心元素

- 系统Logo：居中显示在卡片顶部

- 注册表单（必填项标“*”）：
        

    - 用户名输入框：placeholder“请设置用户名（6-20位字符）”，校验字符长度

    - 手机号输入框：placeholder“请输入手机号”，校验手机号格式

    - 验证码输入框：placeholder“请输入验证码”+ 获取验证码按钮（点击后60秒倒计时，不可重复点击）

    - 密码输入框：placeholder“请设置密码（8-20位，含字母+数字）”，校验密码格式

    - 确认密码输入框：placeholder“请确认密码”，校验与密码一致

    - 用户协议：勾选框+“我已阅读并同意《用户协议》和《隐私政策》”，未勾选无法注册

    - 注册按钮：宽度100%，未勾选协议时禁用，点击后显示加载动画，校验失败显示错误提示

- 辅助入口：已有账号？立即登录：点击跳转登录页

### 3.2.3 交互逻辑

- 输入校验：各字段不符合格式时，实时提示错误（如“手机号格式错误”“密码格式不符合要求”）

- 验证码校验：验证码错误提示“验证码错误，请重新输入”

- 注册成功：提示“注册成功，即将跳转登录页”，3秒后自动跳转登录页

## 3.3 首页

### 3.3.1 页面布局

顶部统计卡片区，中间快捷操作区，底部任务状态区，左侧导航栏，顶部导航栏

### 3.3.2 核心元素

- 统计卡片区（4个卡片横向排列）：


    - 已采集商品：显示数量+“查看全部”链接（跳转已采集商品页）

    - 待发布商品：显示数量+“去发布”链接（跳转草稿箱页）

    - 已发布商品：显示数量+“查看全部”链接（跳转已发布商品页）

    - 今日任务数：显示今日采集/发布任务数量+“查看任务”链接（跳转任务记录页）

- 快捷操作区（3个按钮横向排列，图标+文字）：
        

    - 单链接采集：点击跳转单链接采集页

    - 批量采集：点击跳转批量采集页

    - 一键发布：点击跳转草稿箱页（默认选中待发布商品）

- 任务状态区：
        

    - 标题：近期任务状态（近7天）

    - 表格：任务ID、任务类型（采集/发布）、商品名称、状态（进行中/成功/失败）、操作时间、操作（查看详情/重试）

    - 失败任务：状态标红，操作栏显示“重试”按钮，hover显示失败原因

- 公告栏（右侧侧边栏）：显示系统公告、更新日志、常见问题链接

### 3.3.3 交互逻辑

- 统计卡片点击链接：直接跳转对应页面

- 快捷操作按钮：点击直接跳转对应功能页

- 任务操作：查看详情弹出弹窗（显示任务具体信息），重试按钮点击后重新执行该任务

- 公告栏：点击公告标题查看完整内容，常见问题链接跳转帮助中心

## 3.4 商品采集模块

### 3.4.1 单链接采集页

#### 页面布局

左侧采集输入区，右侧采集结果预览区，顶部导航栏+左侧导航栏

#### 核心元素

- 采集输入区：
        

    - 标题：单链接采集

    - 1688商品链接输入框：placeholder“请输入1688商品详情页链接”，必填

    - 采集选项（勾选框）：
                

        - 采集主图（默认勾选）

        - 采集详情图（默认勾选）

        - 采集SKU规格（默认勾选）

        - 采集商品描述（默认勾选）

    - 采集按钮：点击后显示加载动画，开始采集，采集过程中按钮禁用

    - 重置按钮：点击清空输入框和勾选状态

- 采集结果预览区：
       

    - 初始状态：显示“请输入链接并点击采集”提示文本

    - 采集成功后显示：
                

        - 商品标题：显示采集到的中文标题，右侧有“编辑”按钮

        - 商品价格：显示采集到的1688批发价区间

        - 主图预览：横向滚动，显示所有采集到的主图，点击可放大查看

        - SKU规格：列表显示所有采集到的SKU，右侧有“编辑”按钮

        - 操作按钮：下一步（跳转本地化处理页）、保存草稿（保存至草稿箱）、重新采集

    - 采集失败：显示失败提示（如“链接无效”“反爬拦截，请稍后重试”），加“重新采集”按钮

#### 交互逻辑

- 输入校验：未输入链接点击采集，提示“请输入1688商品链接”

- 采集过程：显示进度提示（如“正在采集主图...”“正在采集SKU...”）

- 采集成功：预览区显示所有采集结果，编辑按钮点击弹出编辑弹窗，编辑后实时更新预览

- 操作按钮：
       

    - 下一步：携带采集数据，跳转至本地化处理页

    - 保存草稿：将采集结果保存至草稿箱，提示“保存成功”

    - 重新采集：清空当前预览结果，重新执行采集操作

### 3.4.2 批量采集页

#### 页面布局

顶部批量输入/导入区，中间任务队列区，底部操作按钮区，左侧导航栏+顶部导航栏

#### 核心元素

- 批量输入/导入区：
        

    - 标题：批量采集

    - 两种输入方式（切换按钮）：
                

        - 批量粘贴：文本框，placeholder“请粘贴多个1688商品链接，每行一个”

        - 导入CSV：文件上传按钮+“下载CSV模板”链接，支持.csv格式文件

    - 采集选项（与单链接采集一致，默认全部勾选）

- 任务队列区：

    - 表格：链接、商品名称（采集成功后显示）、状态（待采集/进行中/成功/失败）、进度、操作（取消/重试）

    - 待采集：状态显示“待采集”，操作栏显示“取消”按钮

    - 进行中：状态显示“进行中”+进度条，操作栏显示“取消”按钮（点击终止采集）

    - 成功：状态显示“成功”（绿色），操作栏显示“查看详情”按钮

    - 失败：状态显示“失败”（红色），操作栏显示“重试”按钮，hover显示失败原因

- 操作按钮区：
        

    - 开始采集：点击后，所有待采集链接进入进行中状态，按钮禁用

    - 清空队列：点击弹出确认弹窗，确认后清空所有待采集/失败任务

    - 导出结果：点击导出所有采集成功的商品数据（CSV格式）

#### 交互逻辑

- 输入校验：未粘贴链接/未导入文件，点击开始采集，提示“请输入或导入1688商品链接”

- 导入校验：导入非CSV格式文件，提示“请导入正确的CSV文件”

- 任务操作：
        

    - 取消：终止当前采集任务，状态变为“已取消”

    - 重试：重新执行该链接的采集操作

    - 查看详情：弹出弹窗，显示该商品的采集结果（与单链接采集预览一致）

- 批量采集完成：提示“批量采集完成，共成功X个，失败X个”，可点击查看失败原因

## 3.5 商品本地化处理页

### 3.5.1 页面布局

顶部本地化选项区，中间内容编辑区（分标签页），底部操作按钮区，左侧导航栏+顶部导航栏

### 3.5.2 核心元素

- 本地化选项区：
        

    - 目标语言：下拉选择（英语、泰语、越南语、印尼语、马来语），默认泰语

    - 自动处理选项（勾选框，默认全部勾选）：
                

        - 标题自动翻译+优化

        - 描述自动翻译+去敏感词

        - 图片自动去水印+OCR翻译

        - SKU自动翻译

    - 一键自动处理按钮：点击后自动完成所有勾选的本地化操作，显示加载动画

- 内容编辑区（4个标签页，切换显示）：
        

    - 标签页1：标题编辑
                

        - 原标题：显示采集到的中文标题（不可编辑）

        - 目标语言标题：可编辑文本框，自动翻译后显示结果，支持手动修改

        - 关键词建议：下方显示平台热门关键词，点击可快速添加到标题中

    - 标签页2：描述编辑
                

        - 原描述：显示采集到的中文描述（不可编辑，可折叠）

        - 目标语言描述：富文本编辑器，支持加粗、换行、插入图片，自动翻译后显示结果，支持手动修改

        - 模板插入：下拉选择售后、物流、品牌模板，点击插入到描述中

    - 标签页3：图片处理
                

        - 主图处理：显示所有主图，每张图下方有“查看原图”“重新处理”“替换图片”按钮

        - 详情图处理：显示所有详情图，操作与主图一致

        - 图片设置：可设置图片尺寸（TK/Shopee标准尺寸）、是否添加水印、水印位置

    - 标签页4：SKU编辑
                

        - SKU列表：显示采集到的SKU（中文），右侧显示翻译后的SKU（可编辑）

        - 添加SKU：点击按钮，弹出表单，可手动添加新SKU

        - 删除SKU：点击每个SKU后的删除按钮，弹出确认弹窗

- 操作按钮区：
        

    - 下一步（智能定价）：点击跳转至智能定价页

    - 保存草稿：将本地化处理后的商品保存至草稿箱，提示“保存成功”

    - 返回采集：返回至上一步（单链接/批量采集页）

### 3.5.3 交互逻辑

- 自动处理：点击“一键自动处理”后，所有勾选的选项自动执行，处理完成后实时更新各标签页内容

- 编辑交互：标题、描述、SKU翻译后可手动编辑，编辑后实时保存（本地缓存）

- 图片处理：
        

    - 重新处理：对图片重新执行去水印+OCR翻译操作

    - 替换图片：点击弹出文件选择框，选择本地图片替换当前图片

    - 尺寸设置：选择TK/Shopee标准尺寸后，自动裁剪图片，提示“图片尺寸已调整”

- 下一步：携带本地化处理后的所有数据，跳转至智能定价页

## 3.6 智能定价页

### 3.6.1 页面布局

顶部定价设置区，中间定价预览区，底部操作按钮区，左侧导航栏+顶部导航栏

### 3.6.2 核心元素

- 定价设置区：
        

    - 标题：智能定价

    - 基础参数（自动填充，可编辑）：

        - 1688成本价：显示采集到的最低批发价，可手动修改

        - 国内运费：默认0，可手动输入

        - 实时汇率：自动获取当前人民币对目标货币汇率，可手动修改

        - 跨境物流费：下拉选择目标国家/地区，自动填充对应物流费，可手动修改

        - 平台佣金率：下拉选择目标平台（TikTok/Shopee），自动填充对应佣金率，可手动修改

    - 利润设置：
               

        - 利润率：滑动条（1.0~3.0），默认1.8，可手动输入

        - 安全边际：固定数值（如5泰铢/1美元），可手动修改

    - 定价公式（显示，不可编辑）：
                售价 = (1688成本 + 国内运费) × 汇率 × 利润率 + 跨境物流 + 平台佣金 + 安全边际

    - 重新计算按钮：修改参数后，点击重新计算售价

- 定价预览区：
        

    - 目标平台：显示选择的平台（TikTok/Shopee）

    - 目标货币：显示对应平台的货币（泰铢/林吉特/越南盾等）

    - 最终售价：显示计算后的售价（加粗，放大显示），可手动修改

    - 价格明细：展开可查看各项费用明细（成本、物流、佣金、利润等）

    - SKU定价：若有多个SKU，显示每个SKU的定价（默认与主售价一致，可单独修改）

- 操作按钮区：
        

    - 下一步（平台发布）：点击跳转至平台发布页

    - 保存草稿：将定价后的商品保存至草稿箱，提示“保存成功”

    - 返回本地化：返回至本地化处理页

### 3.6.3 交互逻辑

- 参数联动：修改任意基础参数或利润设置，点击“重新计算”后，实时更新最终售价和明细

- SKU定价：点击单个SKU的售价，可手动修改，修改后自动保存

- 下一步：携带定价后的所有数据，跳转至平台发布页，自动匹配目标平台的定价规范
